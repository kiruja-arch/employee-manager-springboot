# Employee Management System

## Project Description
A web-based Employee Management System developed using Spring Boot, MySQL, Spring Data JPA, Lombok and Thymeleaf.

## Features
- Add new employees
- View all employees
- Update employee details
- Delete employees
- Employee form validation
- MySQL database integration

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- Lombok
- Thymeleaf
- Maven

## How to Run

1. Install Java 21 and MySQL.
2. Create a MySQL database named `employee_db`.
3. Open the project in IntelliJ IDEA.
4. Configure the database connection in `application.properties`.
5. Run the Spring Boot application.
6. Open the browser and visit:

   http://localhost:8080/employees

## Database Configuration
Update the database username and password in `application.properties` according to your MySQL configuration.
